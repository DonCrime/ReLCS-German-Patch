# ReLCS German Patch

Inoffizieller deutscher Community-Patch für **GTA Re: Liberty City Stories PC Beta 5.0**.

Dieses Projekt wurde von **DonCrime** ins Leben gerufen, damit deutsche Spieler Re:LCS auf dem PC mit deutschen Menüs, Missions- und Untertiteltexten spielen können.

## Features

- Deutsche Menüs
- Deutsche Missions- und Untertiteltexte
- Korrekte Darstellung von `ä`, `ö`, `ü`, `Ä`, `Ö`, `Ü` und `ß`
- Angepasste Tastatur- und Maus-Hinweise für die PC-Version
- Keine Änderung an `gta-lcs.exe` notwendig
- Basierend auf der Re:LCS-Beta-5.0-Textstruktur

## Installation

1. Lade die aktuelle Version unter **Releases** herunter.
2. Erstelle zur Sicherheit ein Backup von:

   `text\german.gxt`

3. Entpacke den Inhalt des ZIP-Archivs direkt in dein Re:LCS-Hauptverzeichnis.
4. Überschreibe die vorhandene Datei, falls Windows danach fragt.
5. Starte das Spiel.
6. Wähle unter:

   `Options -> Language -> German`

   die deutsche Sprache aus.

## Voraussetzung

Benötigt wird:

**GTA Re: Liberty City Stories PC FULL Edition Beta 5.0**

Das eigentliche Spiel ist nicht Bestandteil dieses Projekts.

## Technischer Stand

Die deutsche GXT verwendet weiterhin die PC-Struktur von Re:LCS Beta 5.0.

- 90 Texttabellen
- 6.552 Text-Keys
- Deutsche LCS-Texte in die Re:LCS-Struktur übertragen
- Deutsche Sonderzeichen für die Vice-City-PC-Schrift korrigiert
- PC-Steuerungs-Prompts angepasst

## Bekannte Einschränkungen

Re:LCS Beta 5.0 ist weiterhin eine Beta. Einzelne Fehler des ursprünglichen Projekts können daher weiterhin auftreten.

Die Kamera- und ClassicAXIS-Konfiguration wird durch diesen Patch nicht verändert.
